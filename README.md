# SCP: Containment Protocol

A browser-based 3D SCP survival-horror game built with HTML, CSS, JavaScript, and Three.js.

The player enters a dangerous SCP Foundation facility where containment systems can fail, security levels can change, and different roles have completely different objectives.

## Features

- 3D SCP Foundation facility
- First-person player controller
- Multiple playable roles
  - Guard
  - D-Class
  - SCP
- Playable SCPs
  - SCP-173
  - SCP-096
  - SCP-049
- Multiple game modes
  - Story
  - Containment Breach
  - Facility Lockdown
  - Freeplay
- WASD movement
- Sprinting
- Crouching
- Mouse look
- Flashlight system
- Keycard system
- Interactive doors
- Security levels
- Facility power system
- Objectives
- Inventory system
- NPCs
- SCP AI
- Security cameras
- Facility map
- Pause menu
- Settings
- Save system
- Dynamic facility events
- Multiple endings
- Procedural Web Audio
- Atmospheric lighting and effects

## Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
